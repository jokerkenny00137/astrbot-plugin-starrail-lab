# astrbot_plugin_starrail_lab

一个 AstrBot 插件：输入玩家 UID，查出他在《崩坏：星穹铁道》里公开的角色面板和遗器。

> 本项目与米哈游 / HoYoverse 无关，仅用于个人学习和娱乐。

---

## 功能

- `/面板 <UID>` —— 查询玩家所有展示柜角色的面板
- 面板包含：等级、命座、光锥、攻击 / 生命 / 防御 / 速度、暴击率、暴击伤害、属性伤害加成
- 列出每件遗器的主词条与全部副词条
- 内置缓存，同一玩家 10 分钟内重复查询不会重复请求接口

## 安装

### 前置要求

- AstrBot `>= 4.5.0`
- **Python 3.11 或更高版本**（依赖库 `starrail_damage_cal` 的硬性要求，低于 3.11 装不上）

### 方式一：插件市场

在 AstrBot 的 WebUI「插件」页面搜索 `astrbot_plugin_starrail_lab` 安装。

### 方式二：手动安装

1. 下载本仓库的 ZIP 并解压
2. 把整个文件夹放到 AstrBot 的 `data/plugins/` 目录下
3. 重启 AstrBot，或在 WebUI 插件页点击刷新
4. 确认日志里出现 `[星铁面板] 已加载`

依赖会在插件加载时自动安装。如果自动安装失败，可以手动执行：

```bash
pip install -r requirements.txt
```

## 使用

在任意支持的聊天平台发送：

```
/面板 100000000
```

忽略缓存、强制重新联网查询：

```
/面板 100000000 刷新
```

指令别名：`/星铁面板`、`/查面板`

### 为什么查不到数据

插件读取的是**玩家公开的角色展示柜**，需要满足：

1. UID 输入正确
2. 该玩家在游戏里开启了「角色展示柜」，并且把角色放进去了

如果对方没开，接口不会返回角色数据，插件会提示查不到。

## 数据来源与引用说明

本项目本身不包含任何游戏数值，数据链路如下：

### 1. 计算与数据解析：starrail_damage_cal

- 包名：`starrail_damage_cal`（PyPI）
- 本项目使用版本：`4.6.0`
- 许可证：**MIT**
- 作者：qwerdvd、ilnli
- 地址：https://pypi.org/project/starrail_damage_cal/

该库负责：

- 把 Mihomo / 米游社的角色数据转换为统一模型
- 从遗器主副词条 ID 反算实际数值
- 提供角色基础属性成长表、光锥成长表、词条倍率表等本地资源

本项目只是**调用**它，没有修改其源码。所有属性计算公式（基础值 × (1 + 百分比) + 固定值）实际由该库提供的数据表驱动。

### 2. 数据接口：Mihomo API

- 地址：`https://api.mihomo.me`
- 用途：按 UID 拉取玩家角色展示柜（角色、光锥、遗器词条）

Mihomo 是第三方开源项目，其数据原始来源为米游社 / HoYoLAB 的角色展示接口。本项目不对该服务的可用性、准确性做任何保证。

该接口为公共实例，高峰期可能排队超时，插件对此做了重试和友好提示。

### 3. 游戏内容版权

《崩坏：星穹铁道》及其角色、光锥、遗器、技能名称、数值等内容的著作权归 **米哈游 / HoYoverse** 所有。

本项目：

- 不包含任何游戏素材文件（图片、模型、音频）
- 不提供游戏本体或任何破解内容
- 仅对公开的玩家展示数据进行读取和格式化展示
- 与米哈游 / HoYoverse 无任何关联，未获其授权或认可

## 隐私说明

- 本插件只读取**玩家主动公开**的展示柜数据，不涉及账号登录、密码、Cookie
- 不使用任何私人接口，不绕过任何访问限制
- 查询结果以 JSON 形式缓存在 **AstrBot 的 `data/plugin_data/astrbot_plugin_starrail_lab/cache/` 目录**，默认 10 分钟过期
- 这些缓存**不会**上传到任何服务器，也不会提交到本仓库（已在 `.gitignore` 中排除）
- 如需彻底清除，删除上述 `cache` 目录即可

---

## 已知限制

- **只查展示柜**：玩家没公开的角色查不到，这是游戏机制决定的，不是插件问题
- **不含光锥技能效果**：面板已包含光锥基础属性和遗器词条，但不含光锥的被动技能（如「装备者暴击率提高 8%」），因此与游戏内面板可能存在少量差异
- **公共接口不稳定**：`api.mihomo.me` 排队时查询可能超时，稍后重试即可

## 关于配队伤害计算（实验性，未接入指令）

仓库里的 `team_damage.py` 是早期写的配队伤害计算逻辑，可以在本地用 `test.py` 跑通。

但它依赖的 `starrail_damage_cal` 只实现了 **50 个角色的伤害逻辑，最新只到 2.2 版本的「知更鸟」**。之后的新角色会抛 `UnsupportedAvatarError`。

因此这部分目前**没有**接入 AstrBot 指令，仅作为后续扩展的骨架保留。

## 本地开发

```bash
pip install -r requirements.txt

# 查玩家面板（不需要 AstrBot）

python test.py 100000000 -r

python test.py sample_team.json
```
